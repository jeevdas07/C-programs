# C Programs

A collection of C programs I wrote while learning C as a first-year Computer Science Engineering student at Bannari Amman Institute of Technology (BIT), Sathy.

## About

This repository holds the C programs I have worked out, from basic practice programs to a hackathon project. It helps me practice core C concepts and keep everything in one place for revision.

## Topics Covered (Basics)

- `if` / `else` statements
- `for` loops
- `while` loops
- Arrays
- Strings

## Hackathon Project: Smart Bus

I built this project during my college's first-year C programming hackathon (4 hours).

- **Problem:** Smart Bus, a bus route and passenger management system
- **Team:** Syntax Squad (Jeevesh Muralikrishnan and Sarvesh Periyannan)
- **Language:** C

### Built with AI

The hackathon allowed the use of AI tools, so we used **Claude**, an AI assistant made by Anthropic, to help build this project. Claude helped with planning the program structure, writing and debugging the C code, and explaining the logic of each line. We reviewed the code and made sure we understood how it works.

## How to Compile and Run

You need a C compiler such as GCC.

```bash
gcc program_name.c -o program_name
./program_name
```

On Windows, run `program_name.exe` instead of `./program_name`.
